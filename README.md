# WiFi Inspector

تطبيق ويب عربي لتسجيل بيانات الراوتر، وتدوين نتائج الفحص، وإضافة الأجهزة يدويًا، وتصدير التقارير.

## النشر على GitHub Pages
1. ارفع جميع الملفات الموجودة في جذر المستودع.
2. من Settings ثم Pages اختر Deploy from a branch.
3. اختر الفرع main والمجلد /(root)، ثم Save.
4. افتح رابط GitHub Pages بعد اكتمال النشر.

## ملاحظات
- هذه النسخة لا تحتوي على صور أو أيقونات، ولا تشير إلى ملفات صور مفقودة.
- البيانات تحفظ محليًا في المتصفح على نفس الجهاز.
- لا توجد مزامنة Firebase مفعّلة.
- لا يقوم التطبيق بمسح الشبكة تلقائيًا أو استخراج معلومات خاصة من الأجهزة. أدخل فقط المعلومات التي تظهر لك من لوحة الراوتر أو التي لديك إذن بتسجيلها.
