# WiFi Inspector

تطبيق ويب تقدمي عربي لإدارة بيانات الراوتر والأجهزة المعروفة وسجل نتائج الفحص.

## رفعه إلى GitHub Pages
1. فك ضغط الملف.
2. ارفع كل محتويات المجلد إلى جذر مستودع wifi-inspector.
3. من Settings > Pages اختر Deploy from a branch ثم main و/(root) ثم Save.
4. افتح رابط GitHub Pages مرة واحدة مع الإنترنت، ثم من Chrome اختر إضافة إلى الشاشة الرئيسية.

## الوظائف
- تخزين محلي باستخدام IndexedDB.
- سجل نتائج الفحص اليدوي.
- تسجيل الأجهزة المعروفة وعناوين IP وMAC اختيارياً.
- تصدير تقرير CSV.
- ملفات PWA للتثبيت والتخزين المؤقت.

## حدود هذه النسخة
لا يستطيع تطبيق الويب اكتشاف جميع أجهزة شبكة Wi-Fi تلقائياً. لا بد من تكامل رسمي مع الراوتر أو تطبيق Android أصلي لذلك. المزامنة Firebase غير مفعلة بعد؛ ملف firebase-config.js مجرد خانات إعداد، ويجب تنفيذ المصادقة وقواعد قاعدة البيانات قبل مزامنة البيانات.
